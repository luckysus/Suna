# 科研工作流交互隔离验证

通过可替换服务测试真实 React 交互，尚未接入桌面应用。它不会直接调用 Worker、写主库、激活数据集、接受实验计划或生成测量数据。

两个模型可以选择不同算法、特征顺序和优化方向；按已有数据集的真实列序号选择目标与输入，目标性能列不能成为其他模型的输入。配置变化后旧预览失效，保存新的独立版本并通过只读业务预检后，才允许显式确认执行。

6 项交互测试和 TypeScript 检查已在 Linux 通过，覆盖确认、保存版本、项目切换后的过期响应、错误脱敏、事件刷新与原任务取消接口。当前服务为测试依赖注入，不能宣称真实 Tauri 或 Windows 原生交互已经通过。

在仓库根目录运行 `node tools/development/test-workflow-ui.mjs`；需要先安装仓库现有的锁定前端依赖。
