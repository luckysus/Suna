# 性能预测工作流

## 输入
- 已激活数据集与预测目标（YS、TS、EL、硬度、冲击韧性等），或用户描述的预测需求。

## 步骤
1. 明确预测目标与单位（MPa/%/HV/J），核对数据集中对应列与样本量。
2. 特征选择：成分元素、工艺参数（淬火/回火温度、时间、冷却速度），剔除与目标同源泄漏的列。
3. 模型选择：小样本先线性回归或弹性网建立基线，再尝试随机森林、XGBoost、LightGBM；比较验证集 R²/MAE/RMSE。
4. 训练后必查：验证集指标、特征重要性占比、输入是否落在训练适用范围内（超出范围必须提示风险）。
5. 解释：用精确 SHAP（线性模型）或特征重要性说明各变量贡献，避免把相关性说成因果。
6. 多模型横向比较用模型比较页，输出 R²/MAE/RMSE 对比表。

## 输出
- 预测值 + 95% 预测区间 + 置信度说明。
- 模型指标摘要（训练/验证）与首要影响因素。
- 适用范围警告：输入超出训练分布时明确说明结果仅供探索。

## 边界
- 不在无验证指标时宣称预测精度；不把训练集指标当泛化能力。
- Transformer 等模型需足够样本量，小样本直接拒绝并说明原因。
