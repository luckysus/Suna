# 工艺优化工作流

## 输入
- 已完成的训练任务（性能预测页产出）、优化变量范围与约束（如回火温度 500~650℃）。
- 优化方向：最大化硬度/强度/耐磨性，或最小化成本类目标。

## 步骤
1. 确认模型有效：训练任务已完成且验证指标可接受，否则先回到性能预测页补训。
2. 设定变量与边界：淬火温度、回火温度、保温时间、冷却速度等，边界来自产线实际可调范围。
3. 算法选择：多目标用 NSGA-II，单目标可用 TPE、遗传算法、粒子群或网格搜索；说明选择理由。
4. 约束建模：把工艺互斥与设备能力写成等式/不等式约束，禁止用提示词描述代替显式约束。
5. 结果解读：候选方案表（方案 A/B/C…）+ Pareto 前沿权衡（性能 vs 工艺变量），说明为什么推荐。

## 输出
- 候选方案列表：变量取值、预测值、目标值、可行性。
- 权衡说明：提升主目标的代价是什么（如韧性下降）。
- 下一步建议：把候选方案加入实验计划验证。

## 边界
- 模型只在训练分布内可信，边界外的"最优解"必须标注外推风险。
- 不虚构设备约束；用户未提供的约束必须先询问。
