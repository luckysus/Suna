# 实验设计工作流

## 输入
- 研究目标（如提升耐磨性并保持韧性）、可调变量与取值范围、已有实验数据（如有）。

## 步骤
1. 变量选择：按影响排序挑 2~6 个可控变量，剔除不可控或与目标强耦合无法独立的变量。
2. 方法匹配：
   - 全因子 DOE：因素 ≤4、水平 2~3，需要完整交互信息时使用。
   - 正交实验：因素多但只想均衡覆盖时使用，说明选用的正交表（L4/L8/L9/L16/L25…）。
   - 中心复合响应面（CCD）：需要拟合二阶响应面找极值时使用。
   - 贝叶斯优化：已有 ≥5 组数据、实验昂贵时，按期望改进推荐下一组。
   - 主动学习：想最快降低模型不确定性时，推荐覆盖缺口最大的组合。
3. 生成组合后解释设计结构（试验次数、水平分布、α 取值），让用户知道每个组合的意义。
4. 输出同时加入实验计划，便于追踪执行与结果回填。

## 输出
- 实验组合表 + 每组的设计意图。
- 方法选择理由与预期信息增益。
- 建议同步记录的观测指标（组织、性能、缺陷）。

## 边界
- 变量范围必须来自产线/设备实际能力，不虚构可达范围。
- 已有数据不足 5 行时不用贝叶斯/主动学习，明确提示先积累数据。
