# 数据分析工作流

## 输入
- 数据实验室已激活的数据集（成分、工艺、组织、性能列），或用户粘贴的样本数据。

## 步骤
1. 质量检查：行数、字段数、每列缺失率与异常值（IQR），指出重复列与单位混乱。
2. 清洗建议：缺失值填充策略（均值/保留缺失）与异常值处理的影响，先给建议再动手，由用户确认。
3. 统计解读：均值、范围、分布形态；对目标列（如 YS/TS/EL）给出关键统计量。
4. 相关性：用相关系数热力图指出与目标最强相关的前 3~5 个变量，并提醒相关不等于因果。
5. 深入分析：需要 PCA、聚类或特征重要性时，引导到数据实验室对应面板并解释输出。

## 输出
- 数据质量摘要（行/列/缺失/异常）。
- 关键发现列表：每条附具体数值与来源列名。
- 建议的下一步：清洗方案、可视化或训练哪个性能预测模型。

## 边界
- 不在小样本（<30 行）上给出强分布结论。
- 清洗操作必须由用户在数据实验室确认执行，不直接修改数据。
