# IF 钢分析工作流

## 输入
- 目标牌号（DC04/DC06 或企业 IF 钢）、板厚、r-value 与 n-value 目标。
- 冷轧压下率、连续退火或罩式炉工艺参数、平整延伸率。

## 步骤
1. 核对间隙原子控制：C ≤ 0.003%、N ≤ 0.003%，Ti/Nb 固定策略与过量固定导致的粗大析出风险。
2. 分析 {111} 织构形成路径：热轧板厚与终轧温度、冷轧压下率（75%~85%）、退火温度对 γ 织构的影响。
3. 结合 r-value 数据说明深冲性能，区分塑性应变比的方向差异（r0、r45、r90 与 Δr）。
4. 时效与表面：固溶 C 残留、烘烤硬化响应与表面条纹缺陷的关联。
5. 输出工艺窗口建议时，引用知识库中的实测工艺-性能数据并标注批次数。

## 输出
- r-value 达标判断与主要敏感工艺变量排序。
- 改进建议：压下率、退火温度或成分微调，附证据来源。
- 与文档要求不符的数据点必须显式列出，不得平均化掩盖。

## 边界
- 不外推未经再结晶退火数据支持的 r-value 结论。
- 涉及镀层 IF 基板时单独说明镀层工艺影响。
