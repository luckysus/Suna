# 耐磨钢分析工作流

## 输入
- 用户给出的牌号、板厚、交货状态与服役工况（介质、温度、冲击载荷）。
- 知识库中与牌号相关的标准、质保书、实验数据与文献证据。

## 步骤
1. 确认牌号与执行标准（如 GB/T 24186、EN 10051-2 或企业标准），核对硬度与布氏值范围。
2. 拆解成分体系：C、Si、Mn、Cr、Mo、B、Ni 对淬透性与耐磨相的贡献，注意 Nb/Ti 细化晶粒的作用。
3. 结合工艺路径（TMCP / 淬火 + 低温回火）说明马氏体体积分数、残余奥氏体与碳化物对耐磨性的影响。
4. 磨损机制判断：切削磨损、疲劳剥落与腐蚀磨损的占比，按工况给出硬度与韧性匹配建议。
5. 对比知识库中的实测数据（HBW、-20℃ KV2）与用户工况，标注数据适用边界。

## 输出
- 结论先行：是否满足工况耐磨寿命需求的判断。
- 证据表：每条结论附知识库来源（文档名、页码或数据集行）。
- 风险提示：数据缺失、外推范围与推荐补做的试验。

## 边界
- 不引用未在知识库中出现的标准限值；测值与名义值必须区分。
- 耐磨寿命预测只能给出相对趋势，不做绝对寿命承诺。
