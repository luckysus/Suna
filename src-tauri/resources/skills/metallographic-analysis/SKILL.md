# 金相分析工作流

## 输入
- 用户描述的显微组织照片或观察记录（侵蚀剂、放大倍数、视场位置），及对应工艺与性能数据。

## 步骤
1. 制样核查：取样位置（轧制方向/横截面）、磨抛工序、侵蚀剂（4% 硝酸酒精、苦味酸等）是否与观察目的匹配。
2. 组织判定：按钢种与工艺推断平衡/非平衡组织——铁素体、珠光体、贝氏体（上/下贝）、马氏体（板条/片状）、残余奥氏体。
3. 晶粒度：说明晶粒度等级（GB/T 6394 或 ASTM E112）的评定方式与取样代表性。
4. 组织-性能关联：把组织观察与硬度、强度、韧性数据对应，指出异常组织（如魏氏组织、带状偏析、脱碳层）。
5. 缺陷与异常：表面脱碳、夹杂物级别、带状组织按标准级别图描述，不凭照片臆造级别。

## 输出
- 组织构成描述（体积分数估计注明"目测估计"）。
- 与工艺的对应解释：哪个工艺参数导致该组织。
- 建议：复检位置、补充表征（SEM/EBSD/XRD 残余奥氏体定量）。

## 边界
- 无法从文字描述确证的组织给出"待照片确认"标记。
- 不代替有资质检验员的正式评级结论。
