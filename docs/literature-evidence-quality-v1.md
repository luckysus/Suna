# 文献证据溯源核查 v1

在“文献研究 → 公开发现与本地题录”选择当前科研项目，展开“文献证据溯源核查”，主动点击“核查项目证据”。只读取已经通过原生审核流程归档的数值证据；检索题录、AI草稿和仅在浏览器本页勾选的记录不计入已归档证据。此操作不需要或启用模型API、嵌入API及公网访问。

检查复用现有SQLite、文献证据表、知识库索引、材料字段注册表和不可变成果服务，没有第二套审核表。每条核对工作区、项目、证据正文SHA与原冻结成果，再核对指定文档/版本/片段的文本、内容摘要和定位元数据。索引引用区分匹配、缺失和已变化；不会借用当前最新文档版本代替旧证据版本。

定位元数据存在不表示真实论文页码已核验。索引匹配不表示当前磁盘原文文件字节可用或已校验，`rawSourceBytesVerified`始终为false。DOI关联只检查已保存的本地原文关系，不等于联网核验DOI、版权、撤稿或同行评议。报告不生成统一“科研可信度百分比”。

已知规范字段使用当前项目及领域包实际注册表，调用原有量纲转换，例如1.5 GPa到1500 MPa。保留原值/原单位；未识别字段保持未知，HV/HRC等硬度标尺互不换算，数值溢出不能产生伪造有限值。字段注册表SHA进入快照。不推断论文没有记录的实验条件、测试方法、独立样本数或效应；单位可换算不等于性能可直接比较，不认定不同论文的数值差异就是结论矛盾。

核查预览与保存分开。点击“保存本次核查报告”时，在IMMEDIATE事务中重新读取证据、当前索引和字段配置，逐项比较精确报告SHA；同一来源再次变化，即使仍处于“已变化”状态，观测索引摘要也会使旧预览失效。报告没有随机时间戳，同一快照保存返回同一个成果ID。它作为项目的不可变analysis_result持久化，重开后可在项目成果中读取；旧证据、旧成果、模型状态、数据版本、实验测量均不修改。

每份报告最多1000条证据，页面每次显示25条。空项目可以只读核查，不能制造空的“已验证”报告。归档项目或跨工作区不能保存成果。此阶段是索引溯源和单位核查，不包括原文件重定位、论文实验条件结构化、多论文可比性、效应量/偏倚评价及真实公网服务验收。
