# 科研入门与 M4.6 云端交付

本机架构仍是 React + Tauri 2、Rust Agent Runtime、SQLite 和 Python stdio Worker。科研项目页面提供使用真实项目关联计数的入门引导，数据源和显微组织链接直接打开对应选项卡，不改变当前项目或用户模型配置。

## 第一次使用

1. 在“运行记录”点击“检查计算 Worker”。诊断复用调度器的Worker路径、产物哈希检查和进程隔离，实际加载NumPy、sklearn、SciPy、Pillow、Optuna、XGBoost、LightGBM、ONNX与ONNX Runtime；报告版本、功能可用状态和固定失败码，不输出环境变量、路径或密钥。探测最长20秒，缺依赖不自动安装。
2. 新建课题并“设为当前项目”。任务提交时冻结项目归属，之后切换项目不会改写运行中的来源。
3. 数据实验室导入CSV/XLSX/JSON，确认字段、目标、单位和炉次等分组列后激活。预测页选择实际划分策略；有真实测试集时保留独立测试，避免把同炉样本随机分到训练和测试。
4. 分别训练各性能模型，联合优化逐目标选择模型/方向，设置成分与工艺边界，核对专业规则来源、单位和外推风险。
5. 建立实验计划。只有真实执行后再回录实测、审核并生成新数据版本；再训练和下一轮推荐需用户显式提交。
6. 项目“成果与报告”生成持久化报告、SHA256溯源清单，按原生导出流程保存。manifest是元数据复核清单；完整本机备份在运行记录中进行。

演示文件：[research-synthetic.csv](../examples/research-synthetic.csv)，40条明确合成记录，C为wt%、temperature为degC、HV为HV、J为J，线性关系仅为可重复软件演示，并非钢种配方、商业计算或实验事实。创建独立“合成演示”项目后导入，可训练两个独立模型并验证联合优化。不要将合成候选的模拟值记录为真实实测。真实反馈要求真实测量；自动闭环测试的隔离夹具见`research_feedback_loop`，不会写入用户数据。

## 离线与联网边界

项目、数据处理、本机预测/优化、已安装Worker的图像统计、缓存题录、已有原文证据、报告和备份可离线使用。AI对话和远端Embedding/Reranker需要用户配置的服务；本地全文导入可能调用该Embedding，界面明确取得数据发送确认。公开Crossref元数据检索独立开关，默认关闭；关闭后仍可读SQLite缓存。生产SQL Server是用户配置的外部连接；文件交换适配离线可用，没有自动商业API或设备控制。

## 备份与恢复的范围

格式2增加数据库及每个内容文件的SHA256，预览和恢复均核对。覆盖SQLite、受管objects/indexes、显微原图/缩略图，以及早期规范化和实验反馈生成的material-datasets/research-datasets。数据库源与受管文件哈希不一致时导出失败并清理本次新文件，已有备份不覆盖。

迁移后的受管数据集保留ID、哈希、成果和审核记录，恢复到另一目录时只调整经过哈希验证的物理路径。原始外部CSV等不自动收入备份；返回实际未包含的数据集数量并显示在预览确认中，必须另行保留原文件。备份含本机数据库和文档，元数据manifest的公开分享规则不适用于完整备份。口令仍在系统凭据库，备份保留的是引用；跨机器系统凭据需要重新配置。

兼容读取旧格式1，旧备份没有格式2的覆盖计数及逐文件SHA保证。新格式会被旧版软件拒绝。恢复先验证、暂存、迁移，再替换，失败保留目标；恢复时停任务并重启数据库。耗时导出/预览/恢复移到后台线程，沿用原流程与前端忙状态。本机Windows目录、权限拒绝/磁盘写满和系统凭据恢复尚需原生验收。

领域包安装目录、受管目录外的ONNX/源文件不包含在此格式中。现有恢复流程要求本机领域包路径与签名仍有效，缺失时会拒绝恢复；尚未实现任意跨机器的全自动恢复。移动目录后，旧队列中带绝对文件路径的任务应重新从已恢复的源记录提交；保留原任务和血缘，不把文件不存在包装成计算成功。

## 基准与验收

`scripts/benchmark-research.ps1`执行真实仓储API的1000成果/25条分页与单任务读取，输出合成SQLite基准至`artifacts/research-benchmark.json`。Linux可执行：`cargo test --locked --test research_benchmark -- --ignored --nocapture`。基准报告机器环境、p50/p95/max，不把内存SQLite视为Windows磁盘或百万行性能。前端另有假时钟的一小时未完成任务回归，检查不会伪造超时；它不是实际连续运行一小时的负载验收。已有检索、导入、Agent、启动基准保留。

云端测试与Windows原生验收分别记录。干净用户目录安装、WebView2/DPI、系统对话框、Credential Manager、完整打包Worker/安装包，见[Windows清单](windows-research-acceptance.md)。真实SQL Server、公网Crossref、远端RAG仍按对应说明待验收；没有将回环服务或缓存夹具当成这些实机通过证据。
