# M4.4 文献发现与原文证据

在文献研究选择“公开发现 / 本地题录”。默认读取 SQLite 本地缓存，联网默认关闭。显式启用后才允许用户向所选来源提交检索：Crossref（api.crossref.org）、Europe PMC（www.ebi.ac.uk）或 OpenAlex（api.openalex.org）。只外发关键词、年份和分页游标，拒绝跳转，15秒超时，2MiB响应上限、20条分页，每个工作区/Provider每秒最多一次。取消、错误、重试和断线恢复复用背景任务；关闭联网会停止运行中的请求。服务选择进入原任务载荷和结果；分页沿用返回结果的冻结来源/条件，切换来源后不能误用上次游标。

`LiteratureMetadataProvider` 将请求参数/响应解析与调度、持久化和权限分开；三个实际适配器共用原 SQLite 表、修订仓库和全文流程。旧请求/任务没有 provider 字段时仍使用 Crossref；旧元数据 JSON、字段和 DOI 归一化规则不改变，不新增迁移或覆盖用户配置。生产 IPC 只能选择已注册来源，不能指定任意端点；回环 HTTP 地址仅存在于测试构建。公共题录服务地址属于适配器目录，个人大模型地址、模型名和密钥仍来自既有 ProviderProfile/SecretRef 配置。

DOI 大小写与常见 URL/doi: 前缀归一化，按工作区唯一身份去重，包括不同 Provider 返回同一 DOI 的情况；来源更新追加 SHA256 校验的修订，保留已有修订。无 DOI 的 Europe PMC / OpenAlex 条目分别按来源与 MED/PPR / W 数字 ID 去重。作者、期刊、年份与许可缺失即显示未记录。`isOpenAccess` 或元数据中的许可不是原文授权审核，条目始终 `link_only`。题录加入项目仍标“metadata only / 无原文”，不能从摘要推测实验数值。BibTeX 使用原生文件导出。年份统计注明当前分页的用户检索集合，不代表整个领域。

OpenAlex 目前使用公开文档描述的匿名检索，不附带 API Key、邮箱或本地文件，不借用 LLM 配置。采用固定 works 端点、search / 年份过滤和不透明 cursor；服务端提供的下载地址、主页和跳转地址不作为后续请求目标。作者与正文预算有界；倒排摘要只按完整且无冲突的位置还原，拒绝缺词、重复位置或过大索引，不编造摘要。许可只记录来源明确给出的字段，开放获取状态不推断许可；撤稿、全文版权和科学有效性仍未核验。401/403 返回 `literature_authentication_required` 且不自动重试认证；429 继续走原任务的有界重试。付费账户/密钥模式尚未实现，服务当前访问政策和匿名额度仍需真实公网验收。

全文由用户提供有权使用的 PDF/Markdown/TXT/DOCX，需选择现有本地知识库、实际嵌入 Provider/维数和所需解析 Provider，并确认版权及可能向当前 RAG Provider 发送全文/片段。复用原 import_local_document 与索引任务，不绕过付费墙、不自动下载期刊 PDF。没有已配置 Provider 时不可伪称索引完成，原知识库配置不会被覆盖。

本地证据检索复用 FTS，显示真实 document/version/chunk 和页码/章节。归档时 Rust 校验工作区、片段哈希、逐字引用、数值与单位配对、字段单位兼容以及 DOI 与全文版本的关联。人工确认生成不可变审核证据，随后可以导出或创建新的数据实验室草稿，来源明确为 literature。未审核的旧 AI 草稿保留原流程，不自动转入新原生审核库或训练。新 JSON 表格读取支持对象数组、有限数值、缺失字段和嵌套溯源 JSON 单元格，64MiB/256列/十万预览行上限。

原 M4.4 历史验证为 Rust 7项、前端273项；原生 Markdown→真实文档版本/片段→审核→新草稿与重开通过，不能沿用该数字作为新适配器结论。来源适配见 [Europe PMC 验证](../validation/2026-10-15-literature-providers.md) 与 [OpenAlex 验证](../validation/2026-10-15-openalex.md)。三种来源均执行真实本地 HTTP→原 Scheduler→修订缓存/项目来源→关闭联网后离线读取/重开测试，但未执行真实公网验收；Crossref先前公网403/连接受限结论不视为恢复。远端嵌入/解析 Provider、OA/PDF版权及 Windows 原生导入仍待真实环境验证。

## 人工引用的实验条件

“文献实验条件与测试方法”以项目中已有的人工审核数值证据为起点。主动读取来源，选择原数值证据，再检索同一文献版本中的条件片段。支持材料体系、成分、热处理、显微组织、测试方法和其他测试条件六种人工分类；条件文字必须逐字包含在引用中，引用必须包含在实际片段中。成分保留原文单位，系统不推断工艺顺序、单位或跨论文可比性。

原生保存同时校验工作区、活跃项目、原证据正文及 SHA、冻结文献版本和实际片段 SHA。明确确认后，在同一 SQLite 事务中追加 `literature-experimental-context.v1` 成果、`based_on_evidence` 血缘和审核记录。重复提交相同条件返回原成果，不重复审核；修改条件产生新成果，原数值证据及其历史摘要不变。来源和历史均每页25条，历史可以退出重开读取；当前页 JSON 导出复用原生保存服务及其取消、覆盖和错误处理。

本地检索只允许当前工作区拥有的知识库，最多256个，超额明确拒绝。FTS 的空权限列表仍表示无权检索；返回片段需与实际存储文字及 SHA 一致，不使用未校验的缓存片段。索引仍只检索活跃文献版本：若原证据冻结的旧版本已不活跃，界面不能自动换用新版本补充条件，需要在正常文献版本流程中核对来源；已保存的旧条件历史仍可读取。

条件记录是独立的原文引用成果，尚不自动合并进文献训练草稿，也不触发模型、数据集、实验测量或 Agent 工具执行。原有数值证据核查 v1 不评价补充条件，不据此认定两篇论文可以直接比较。原始 PDF 字节、版权、实际实验及真实服务仍须另行核验。验证见 [实验条件记录](../validation/2026-10-15-literature-experimental-context.md)。
