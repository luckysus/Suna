# M4.4 文献发现与原文证据

在文献研究选择“公开发现 / 本地题录”。默认读取 SQLite 本地缓存，联网默认关闭。显式启用后才允许用户提交 Crossref 检索；只外发关键词、年份和分页游标，固定 api.crossref.org，拒绝跳转，15秒超时，2MiB响应上限、20条分页和每工作区每秒一次限流。取消、错误、重试和断线恢复复用背景任务；关闭联网会停止运行中的请求。

DOI 大小写与常见 URL/doi: 前缀归一化，按工作区唯一身份去重，来源更新追加 SHA256 校验的修订，保留已有修订。作者、期刊、年份与许可缺失即显示未记录。题录加入项目仍标“metadata only / 无原文”，不能从摘要推测实验数值。BibTeX 使用原生文件导出。年份统计注明当前分页的用户检索集合，不代表整个领域。

全文由用户提供有权使用的 PDF/Markdown/TXT/DOCX，需选择现有本地知识库、实际嵌入 Provider/维数和所需解析 Provider，并确认版权及可能向当前 RAG Provider 发送全文/片段。复用原 import_local_document 与索引任务，不绕过付费墙、不自动下载期刊 PDF。没有已配置 Provider 时不可伪称索引完成，原知识库配置不会被覆盖。

本地证据检索复用 FTS，显示真实 document/version/chunk 和页码/章节。归档时 Rust 校验工作区、片段哈希、逐字引用、数值与单位配对、字段单位兼容以及 DOI 与全文版本的关联。人工确认生成不可变审核证据，随后可以导出或创建新的数据实验室草稿，来源明确为 literature。未审核的旧 AI 草稿保留原流程，不自动转入新原生审核库或训练。新 JSON 表格读取支持对象数组、有限数值、缺失字段和嵌套溯源 JSON 单元格，64MiB/256列/十万预览行上限。

验证：Rust 7项通过，包括真实本地 HTTP 夹具→原 Scheduler→修订缓存→项目溯源→关闭联网后离线读取；原生 Markdown 解析→真实文档版本/片段→审核→新草稿数据集与重开也通过。前端273项通过。Crossref公网烟测已实际尝试，当前云端返回403/连接拒绝，未通过真实公网验收；测试专用回环地址不能由生产 IPC 配置。远端嵌入/解析 Provider、实际 OA/PDF版权及 Windows 原生导入仍待真实环境验证。
