# 科研扩展 Windows 原生验收（待执行）

云端 Linux 的 Rust/Python、Chromium IPC 夹具及布局检查不能替代以下验收。此清单不代表通过记录。

- 干净 Windows 用户目录安装，离线启动；Python Worker 缺失/缺依赖的诊断准确且可恢复。
- 从迁移 0035 与 0039 的隔离数据库升级，旧数据和凭据引用保持完整；备份后重复启动没有重复迁移。禁止使用生产数据库测试。
- 中文、空格路径创建项目、导入 CSV/图像、训练与优化；退出并重启核对当前项目、来源任务和 SHA256。
- Agent 开始后切换项目，原任务在 Inspector、原项目和专业页 ID 一致；工具被禁用或未确认时不能写项目。
- 项目报告、manifest 与科研项目元数据 ZIP 的原生保存、取消、文件已存在的覆盖确认、权限拒绝、磁盘写满；DOCX/PPTX 能用本地软件打开，PDF 系统打印可取消。
- 1366×768、125%/150% 系统 DPI、窗口缩放；浅深主题与 reduced motion、Tab/Shift+Tab 焦点闭环、Escape 关闭和返回触发控件。
- 本地 SQL Server 凭据及 Windows 集成认证按驱动实际支持验证；只读白名单、参数、行/字节预算、取消和超时，不在真实生产库运行。
- 保存进程日志时不得包含密码、密钥、模型 Blob 或企业原始数据；联网关闭后基础科研功能仍可使用。
- 格式2备份在另一中文目录恢复：逐文件/数据库SHA256、图像及标注、规范化和测量数据路径、项目/成果/审核ID不变；外部原始文件未包含的实际数量可见。缺文件、改字节、旧格式1、磁盘不足时不得误报恢复成功。跨机器系统凭据需重新配置，备份不复制口令。
- 离线诊断分别测试缺Worker、错误产物哈希、缺依赖/DLL、协议不兼容与20秒探测上限；随后执行实际预测/优化和图像任务。依赖加载通过不等于安装包或全部算法验收通过。
- 一小时及以上真实长任务、断线/退出重启、取消/重试和完成通知；云端假时钟回归不能替代此项。运行`benchmark-research.ps1`及已有四项性能基准，保存Windows机器环境与原始报告。
