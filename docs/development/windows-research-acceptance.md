# 科研扩展 Windows 原生验收（待执行）

云端 Linux 的 Rust/Python、Chromium IPC 夹具及布局检查不能替代以下验收。此清单不代表通过记录。

- 干净 Windows 用户目录安装，离线启动；Python Worker 缺失/缺依赖的诊断准确且可恢复。
- 从迁移 0035 与 0039 的隔离数据库升级，旧数据和凭据引用保持完整；备份后重复启动没有重复迁移。禁止使用生产数据库测试。
- 中文、空格路径创建项目、导入 CSV/图像、训练与优化；退出并重启核对当前项目、来源任务和 SHA256。
- Agent 开始后切换项目，原任务在 Inspector、原项目和专业页 ID 一致；工具被禁用或未确认时不能写项目。
- 项目报告、manifest 与科研项目元数据 ZIP 的原生保存、取消、文件已存在的覆盖确认、权限拒绝、磁盘写满；DOCX/PPTX 能用本地软件打开，PDF 系统打印可取消。
- 1366×768、125%/150% 系统 DPI、窗口缩放；浅深主题与 reduced motion、Tab/Shift+Tab 焦点闭环、Escape 关闭和返回触发控件。
- 本地 SQL Server 凭据及 Windows 集成认证按驱动实际支持验证；只读白名单、参数、行/字节预算、取消和超时，不在真实生产库运行。
- 保存进程日志时不得包含密码、密钥、模型 Blob 或企业原始数据；联网关闭后基础科研功能仍可使用。
- 格式2备份在另一中文目录恢复：逐文件/数据库SHA256、图像及标注、规范化和测量数据路径、项目/成果/审核ID不变；外部原始文件未包含的实际数量可见。缺文件、改字节、旧格式1、磁盘不足时不得误报恢复成功。跨机器系统凭据需重新配置，备份不复制口令。
- 离线诊断分别测试缺Worker、错误产物哈希、缺依赖/DLL、协议不兼容与20秒探测上限；随后执行实际预测/优化和图像任务。依赖加载通过不等于安装包或全部算法验收通过。
- 一小时及以上真实长任务、断线/退出重启、取消/重试和完成通知；云端假时钟回归不能替代此项。运行`benchmark-research.ps1`及已有四项性能基准，保存Windows机器环境与原始报告。

数据规范化与显式激活原生记录（全部 `NOT_RUN / pending-native`）：

1. 在隔离项目导入合成 CSV，原文件保留。原始版本没有确认映射时不能激活，预测/工作流不能使用草稿。
2. 在材料字段面板手动选择真实注册字段与原始单位。以 C/temp/HV/J/time 合成文件为例：C → `chem.c` / wt%，temp → `process.quench_temperature` / degC，HV → `property.hardness_hv` / HV，J → `property.impact_energy` / J。time 仅作时间划分辅助列时保留“不转换此列”，不要把时间顺序伪装为保温时间。
3. 点击“确认映射与单位，创建新版本”。应选中新生成的规范化草稿；它有自己的 ID、文件和 SHA。原文件 SHA 不变，不能把规范化文件 SHA 当作原始 SHA；数值格式或单位转换可使两者不同。
4. 在上方核对**已保存**的列映射、单位与来源 SHA，勾选确认后点击“确认激活此数据集”。只有原生接口成功后显示已激活，再去预测/科研工作流选择该版本。仅填写下方映射表不会修改或激活现有版本。
5. 核对后若源文件字节改变，或另一操作改变了保存版本，激活必须拒绝且不能显示成功。刷新重新核对；不要修改生产数据来造故障。切换数据集时，旧请求的迟到回复不能替换当前选中项。
6. 退出重开，核对版本仍为 ready、ID/来源 SHA/字段单位与映射修订/冻结成果 SHA 一致；原版本仍是原状态。激活数据集不会激活模型、创建训练任务或写入实验测量。

记录原始与规范化两个 ID/SHA、实际原生请求结果和脱敏错误。云端 SQLite/IPC 夹具通过不代表上述 Windows 操作已通过。

工作流固定变量与线性约束原生记录（全部 `NOT_RUN / pending-native`）：

1. 在已激活的合成数据版本上配置两个独立模型。固定 `chem.c` 为范围内的一个值，在“线性配比约束”添加等式或不小于约束；温度上限用负系数和负阈值。按变量显示的单位填写系数、阈值与容差，不把 wt% 数值当作 fraction。保存模板新修订，退出重开后逐项核对。
2. 先完成只读预览并勾选确认，再改变一个固定值、系数、阈值或容差。原预览和确认必须失效；重新保存、预览和确认之前不能开始。移除约束引用的特征时应提示缺失变量，不能无声删除该系数；恢复变量或显式删除约束后再配置。
3. 固定成分与线性下限互相冲突、手工约束与已审核专业硬规则互相冲突、固定值越界、未知变量、非有限输入均不得创建任务。记录预览前后任务数量。约束合计最多64条；线性可行性预检最多24个变量，超过复杂度或数值预算应明确拒绝，不能截断或忽略规则。
4. 确认后执行真实训练和联合优化，逐项核对候选的固定值、范围、等式绝对残差及不等式残差。生成的实验计划保持 proposed，显示冻结的优化变量单位；旧成果没有单位元数据时保持未知，不根据当前数据集猜测。关闭重开后，模板、约束、计划单位与冻结成果 SHA 保持一致，模型不自动激活、不自动写实测。

记录模板 ID/修订/摘要、数据 ID/SHA、完整约束表达式及单位、固定值、预览摘要、实际任务/成果/计划 ID、计划状态、实测数量和实际错误。数学可行性与模型适用域、统计预测区间、真实设备验收分别核对，不能互相替代。

2. 预览后变更项目内容或源文件，导出应拒绝过期摘要。中文路径保存、取消、覆盖确认、拒绝写入/空间不足均据实记录；只有回读校验后提示成功，原文件和原模型摘要不变。
