# 显微组织工作台（M4.3）

在数据实验室选择“显微组织”，先选择科研项目，填写样本和来源再导入。支持 PNG/JPEG 8 位、PNG 无符号 16 位灰度，以及单页普通 TIFF（8 位灰度/RGB、无符号 16 位灰度，支持大小端）。单图最多 32MiB、1600万像素、边长8192。TIFF 多页、金字塔/子图、非标准方向、浮点/有符号样本、WhiteIsZero、平面 RGB、16 位 RGB/Alpha 和厂商 EBSD 原始数据尚不支持，导入前拒绝，不会静默取第一页。原始图像按 SHA256 保存到管理目录，缩略图单独保存；没有图像 Base64 写入 SQLite。

16 位灰度须先明确选择“完整量程 0–65535”或“指定灰度窗口”；没有选择则拒绝导入。窗口必须是 0–65535 内递增整数。显示和分析共用 `linear-u16.v1`：`floor((clamp(v, lower, upper)-lower)*255/(upper-lower))`。不自动按本图最小/最大值拉伸，阈值和直方图仍针对映射后的 0–255 灰度。此选择不作用于 8 位图像。采集位深和仪器有效位数不是一回事，记录的是解码样本位深，不能据此推断曝光、动态范围或材料状态。

新导入记录将 `microstructure-input.v1` 保存到原图不可变元数据和成果快照：格式、解码位深、灰度/RGB、宽高、EXIF 方向解析值、原始栅格坐标、忽略方向、透明白底、未做 ICC 色彩管理及灰度映射上下限/取整规则。新任务提交冻结同一协议，Worker 校验实际原文件和处理参数，结果按 `microstructure.v2` 追加保存；本地结果登记再次核对源 SHA、协议和尺寸。旧图像/旧任务没有协议时仍走 `microstructure.v1`，历史图像、ROI、结果及成果摘要不重算。预览仅缩小不放大，原始像素始终保留。

“标尺两点”可点击图像或用像素 X/Y 键盘输入，然后填写真实长度和 μm/mm。倍率仅作采集元数据；没有标尺时结果不含物理长度/面积单位。矩形选择两角，多边形选点后点击完成，多 ROI 按像素中心的并集计算。可以重置当前编辑内容；保存会创建新不可变版本。

先选择灰度/阈值掩模预览，再保存标注或提交原图分析。缩略图经过降采样，只用于导航；Python 的完整原图统计是计算事实源。透明像素合成白底，坐标基于原始栅格，不采用 EXIF 旋转。阈值为灰度≥给定整数，直方图仅包含 ROI，区域占比按选中像素/ROI像素计算。

勾选确认分割后才生成四邻接连通区域的像素面积和等效直径；有标尺再给出 μm²/μm。这些区域没有经过晶粒边界或材料相验证，不能解释为马氏体占比或精确晶粒尺寸。超过一万区域会明确报错，避免输出无界列表。

批量选择最多20图，固定当前阈值和 ROI，并保留各图独立的已保存标尺。每张图的标注 ID/哈希在提交时冻结，之后编辑不改原任务；错误按图记录，缺原图/哈希变化不会伪造统计结果。任务复用原 Scheduler、stdio Worker、取消/重试/恢复。审核形成追加记录和成果边；Agent 读取工具只返回人工接受的统计，提交分析需要原有权限确认和冻结项目范围。

项目报告读取原图来源、分析参数和审核成果。统计 JSON 沿用 Rust 原生保存对话框。原图和预览已纳入现有备份的内容白名单，导出 manifest 仍是元数据清单，不能独立恢复文件。

原工作台的历史云端验证为 Python 151通过/2打包验收跳过、Rust 图像仓储4通过、图像 Scheduler+Worker 和旧双模型闭环各1通过、前端图像4通过；这些不是当前输入扩展的验收结论。输入协议与像素金标准见 [本次验证记录](../validation/2026-10-14-microscopy-input.md) 和 [合成像素夹具](../../fixtures/microstructure/README.md)。Windows 原生导入/显示/路径/Worker安装包仍按验收清单待验证。没有新增晶粒、材料相识别、EBSD 分析或科学图像真值评估。
