## 访问政策与安全

依据实际读取的 [OpenAlex 公开文档](https://github.com/ourresearch/openalex-docs/blob/8cec9dba1ee17af56e5de4666f63650a02fb798b/how-to-use-the-api/rate-limits-and-authentication.md) 与该版本分页、works 字段说明，本期使用匿名模式。不附带 API Key、邮箱、个人模型凭据或本地原文，不设置隐含账户。没有调用真实 OpenAlex 搜索来代替用户授权验收，也没有声称当前公网访问政策或额度已通过验证；付费密钥模式尚未实现。

401/403 在读取正文前返回稳定的 `literature_authentication_required`，不自动重试认证；429 沿用原任务的有界重试，重定向不跟随。响应限制、超时、取消、关闭联网和事务内检查仍沿用现有实现。任意 endpoint / api_key 输入不属于 Search 契约，不能把检索词中的 `&api_key=` 变为额外请求参数。
